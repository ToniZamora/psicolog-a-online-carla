# Psicología Online Carla

Quiero crear una página web para mi novia que es psicóloga, me gustaría que fuese algo sencillo, con un campo para rellenar de una imagen suya, un campo para hablar de ella misma, y algún campo más interesante que hiciese llamativa la página , quiero que sea una página royo portal web, con un enlace a su watshapp para que cuando la gente clicke pueda mandar un mensaje, quiero que crees tu la página entera y me des a mi el dominio para poder añadir los campos que faltan yo manualmente.
